# Landfall Display

The Flutter client for Landfall — a full-screen ambient display for TV and monitor.

## Running the app

```bash
# macOS desktop
flutter run -d macos

# Connected TV / Fire TV (replace <device-id> with output of `flutter devices`)
flutter run -d <device-id>
```
