# landfall_client

The generated Serverpod client for the Landfall server. Code in `lib/src/` is generated by `serverpod generate` — do not edit it directly.

## Regenerating

After any endpoint change in `server/landfall_server/`:

```bash
cd server/landfall_server
serverpod generate
```

This overwrites `server/landfall_client/lib/` with updated generated code. Commit the diff in the same PR as the endpoint change — a stale client causes a fatal `ExitException(1)` at server startup.

See [`doc/endpoint.md`](doc/endpoint.md) for the full list of available endpoints and their parameters.
