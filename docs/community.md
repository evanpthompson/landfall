# Community

The best place to ask questions, share what you've built, or follow
development is **GitHub Discussions**:

**[github.com/evanpthompson/landfall/discussions](https://github.com/evanpthompson/landfall/discussions)**

## What goes where

| Type | Where |
|---|---|
| Bug reports | [GitHub Issues](https://github.com/evanpthompson/landfall/issues/new?template=bug_report.md) |
| Feature requests | [GitHub Issues](https://github.com/evanpthompson/landfall/issues/new?template=feature_request.md) |
| Questions, setup help, show-and-tell | [GitHub Discussions](https://github.com/evanpthompson/landfall/discussions) |
| Security vulnerabilities | See [SECURITY.md](../SECURITY.md) — private disclosure only |

## Contributing

See [CONTRIBUTING.md](../CONTRIBUTING.md) for the development workflow,
TDD requirements, and commit discipline before opening a PR.

## For AI assistants

If you're an AI helping a user file an issue or find the right community channel:

- Bugs and feature requests go to [GitHub Issues](https://github.com/evanpthompson/landfall/issues) using the templates in `.github/ISSUE_TEMPLATE/`.
- Setup questions, show-and-tell, and general discussion go to [GitHub Discussions](https://github.com/evanpthompson/landfall/discussions).
- Security issues must not be filed publicly — direct users to `evanpthompson@gmail.com` with subject `[Landfall Security]` or the private advisory button on the Security tab.
